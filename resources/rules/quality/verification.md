# 验证依据

规则标识：QUALITY-VERIFY。定义测试范围、执行检查或判断完成时使用。

## 本次验证

- 验收条件使用稳定编号，例如 `AC-1`，每项至少映射一个具体测试文件或用例引用。
- 记录验证命令、实际结果、退出码、提交和代码树摘要；命令执行与外部报告结果分开标明。
- 失败、跳过、未运行和环境限制不能写成通过。套件正常退出不自动等于每个用例通过。
- 代码、测试或范围变化后，旧验证过期，需要重新执行或明确说明影响。

## 测试范围

按实际影响选择单元、接口、集成、场景、性能、安全、可靠性、兼容性和易用性检查；不适用项说明理由。长期用例按稳定模块、跨模块场景和系统质量组织，不为小改动强制建立整套验证文档。

## 记录方式

默认由 `verify` 和 `check` 维护验收条件到测试引用的覆盖。工作记录只保留可重跑的命令与结果，不保存原始日志、全文快照、自举工程或安装包。需要详细证据时从 Git 取回或重新运行。
