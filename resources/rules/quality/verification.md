# 验证依据

规则标识：QUALITY-VERIFY。定义测试范围、执行检查或判断完成时使用。

## 本次验证

- 验收条件使用稳定编号，例如 `AC-1`。需求确认后先把每项转为全局用例，写清前置条件、步骤、输入、预期结果、类型、优先级和来源 AC，再由测试引用用例编号并实现。
- 设计确认后每项条件至少映射一个带完整测试设计的用例；验证或验收时，每个用例必须有至少一个在测试名或紧邻注释中引用它的测试，且本次验证覆盖、已核实、未过期。测试引用不存在的 CASE 编号是错误。
- `verify` 只声明 `--test "<文件::测试名>"`，由 tiller 构造并执行精确匹配的 node:test 命令；记录用例编号、实际命令、结果、退出码、核实状态、提交、代码树摘要和本机日志路径。
- 结果只从 tiller 私有临时报告读取，stdout/stderr 不参与判定。文件、完整名称（嵌套按名称路径）必须精确匹配且仅命中一个通过事件，且无失败；仅引用文件时要求全部通过。报告缺失/损坏、0/多个匹配、失败或跳过都不能核实。
- `verify.prepare` 可在 `project.json` 配置测试前准备命令（参数数组），失败即验证失败；`verify.runner` 缺省 `node-test`，也可为 `junit-maven`、`junit-gradle` 或 `pytest`。pytest 构造私有 `--junitxml` 报告并从 XML 精确核实，不内嵌 Python、不自动安装依赖。工作区每条仓库记录可用 `verify` 覆盖 runner 与 prepare，准备和测试的工作目录是该业务仓库根。测试路径不能唯一归属已登记仓库时拒绝执行，不按扩展名猜测语言。新增框架在 `src/test-output.ts` 实现 `TestRunner` 的构造命令与报告解析并注册。
- 外部报告使用 `--reported --command --result --reason`，理由必填；默认阻断，只有 `--allow-reported` 显式放行并在 PR/MR 草稿标明未执行。
- bugfix 任务使用 `--expect-fail --test` 在基线临时工作树走同一适配器和报告路径证明失败，并保留当前同一测试的已核实通过记录。
- 失败、跳过、未运行和环境限制不能写成通过。套件正常退出不自动等于每个用例通过。
- 未验收任务在代码、测试或范围变化后，旧验证过期，需要重新执行或明确说明影响。已验收任务以 acceptance 记录中的提交为检查终点：从该提交读取代码树与测试文件，不因后续代码漂移误报过期；若验收时的证据本就不完整，仍按原记录失败并指出当时问题。
- 已验收任务不再要求当前工作树干净；未验收任务仍检查范围内的未提交改动。任务基线后没有 `.tiller/specs/` 或 `.tiller/context/` 回写时，`check` 给出建议路径、简短提纲和 warning，由人判断是否为长期结论。同一 AC 或同一 CASE 连续两次失败且中间无成功核实时，`verify`/`check` 要求停止自动重试并报告证据与 2～3 个可选方案；成功核实清零。

## 测试范围

按实际影响选择单元、接口、集成、场景、性能、安全、可靠性、兼容性和易用性检查；不适用项说明理由。长期用例按稳定模块和跨模块场景组织，不为小改动强制建立整套验证文档。

模块用例位于 `.tiller/cases/modules/<模块>/{behavior,interface,performance,security}.md`，模块名须与 `.tiller/specs/modules/` 一致；跨模块端到端路径位于 `.tiller/cases/scenarios/`，每条声明经过的 `modules`。类型文件按需建立，不建空文件。

每个用例至少包含稳定编号、标题、前置条件、步骤、输入、预期结果、类型、优先级、需求/模块引用、源码路径和来源 `criteria`。用例不保存测试引用字段；tiller 扫描测试名或紧邻注释中的 `CASE-NNN` 建立反查。无引用显示待实现，编号跨文件和场景唯一。

## 记录方式

默认由 `verify` 和 `check` 维护 AC→测试设计用例→引用测试→当前验证的覆盖。`case add` 自动分配编号，不要求测试已存在；`verify --test` 记录测试名引用的用例，`verify --case` 执行覆盖该用例的全部测试；`check` 分阶段阻塞缺失用例、待实现、失效、错配、未回指当前 AC 或过期映射，报告各模块各类数量、场景和未覆盖模块，并在改动涉及模块时提示回归其用例和经过它的场景。任务记录只保留实际命令、结果和日志路径；完整输出写 `.tiller/local/logs/` 且不提交，需要时从 Git 取回或重新运行。
