# 实现

规则标识：ACT-IMPL。编写代码、配置或测试时使用。

## 范围

- 只修改本次声明的文件范围。顺手发现的问题记录到任务记录，不扩大范围修复。
- 需求确认有效；标准开发任务还需要有效的设计确认。前置确认缺失时暂停依赖它的实现。
- 发现目标、接口或关键行为需要变化时，先展示影响并重新确认受影响内容。

## 质量

- 新增或调整测试来覆盖验收条件，不在未说明的情况下删除、跳过或弱化测试。
- 执行与改动范围最接近的检查，再按风险扩大。读取实际退出状态和结果，失败先查明原因。
- 同一问题连续两次修复失败后停止自动尝试，报告现象、已尝试方法、证据和两到三个可选方案。
- 不在记录中写密钥、token、凭据或本机绝对路径。

实现完成后运行自检，记录命令、结果和提交；验证失效时重新执行，不只更新文字。
