# tiller 规则索引

先读[共同动作](core.md)和[使用指引](../usage.md)。项目规则、背景和已有决定按工程索引查找；实际存在的项目专属约定继续适用。

| 当前活动 | 执行指引 |
|---|---|
| 开始、接续、范围、卡住或完成 | [共同动作](core.md) |
| 编写需求 | [需求编写](activities/requirements.md) |
| 编写设计 | [设计编写](activities/design.md) |
| 实现代码或测试 | [实现](activities/implementation.md) |
| 验收、交付或发布 | [交付](activities/delivery.md) |
| 文档组织与质量 | [文档质量](quality/documents.md) |
| 测试范围与证据 | [验证依据](quality/verification.md) |

规则按需读取。命令参数和任务记录格式以 `--help` 及命令提示为准；不预置文档模板，单次变更优先引用已有规格并在 `task.md` 记录，跨任务回归按 `.tiller/cases/modules/` 与 `scenarios/` 声明。
