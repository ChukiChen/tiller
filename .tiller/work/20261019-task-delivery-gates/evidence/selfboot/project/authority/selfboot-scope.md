# T6 受控自举执行范围

本工程只执行已确认门禁工作 T6 的验证，不开发新的业务产品。原需求、设计、规划及真实确认来源保存在 authority/；机器请求在既有授权后登记，不声称用户此前看过新生成的展示。

A：实际运行安装后固定入口探针。先用故意错误的版本期望观察失败及下游拒绝，再修正为候选包的实际约定版本 0.4.0，重新运行并验证。B：依赖 A 的操作与接续说明；开始后保存进度并交给另一执行者从持久资料接续，再完成说明和组合检查。每一步分别执行、读取结果后决定下一步，不用一次性脚本模拟执行者判断。

不登记最终用户验收，不执行提交、推送、评审创建、合入、发布或外部业务仓库修改。所有用户批准仅指既有 T6 执行授权；新的人工作业判断若超出该范围必须保持待确认。

原规划批准时摘要见 planning-confirmation-source.md；本次保存的 plan.md 是任务范围与验证条件不变的进度更新版本，不能将两者声称为全文摘要相同。人工观察是执行者技术检查，不是新增用户批准节点。
