# 隔离交付实施记录

日期：2026-10-15。对应已确认的工作推进设计第 11 节。当前记录实施事实，不代替交付验收。

## 实现范围

- TypeScript 使用本机 Git 和内置 HTTP 能力，无新增第三方依赖。交付环境、路径定位、动作及平台适配分开实现。
- prepare 采用计划摘要与显式应用，核对有效设计、仓库身份、基线和目标。单仓库与独立管理布局分开，管理资料只有一个活动来源，未跟踪资料按明确清单交接。
- delivery.json 记录交付单元和操作；本机定位与恢复资料位于 local/。现有工作命令按活动位置接续，业务引用通过逻辑仓库解析，写锁使用管理根。
- commit、push、review 使用独立授权来源复核和对象快照；已有暂存区、过期输入和远端漂移不能直接执行。GitHub/GitLab 支持真实创建、更新和查询接口，但测试只使用本机模拟服务。
- merge 请求绑定资料版本、源/目标提交、评审身份、依赖与检查。内置平台适配不具备源/目标双重原子合入能力，因此自动合入明确拒绝；由受保护的人工流程完成后，reconcile 保存实际观察结果，缺少授权证据时不宣称已授权合入。
- 确认格式更新为 schemaVersion 2；旧格式只读及显式迁移保留原始字节，不生成历史批准。文档 record.json 继续使用 schemaVersion 2，已有文档工作不自动生成 delivery.json。
- 通用入口、共同规则、实现及交付规则增加活动目录和合入边界，0.2.2 工程可以显式升级到 0.3.0；现有自定义规则及工作资料保留。

具体输入示例在 [README](../../../README.md)；这里不复制另一套接口定义。
